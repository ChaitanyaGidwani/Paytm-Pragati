# Paytm Pragati (पेटीएम प्रगति) 🚀
### The Voice-First, Multilingual Merchant Growth Copilot for Bharat

> **Turn Soundbox & QR payment streams into automated, 1-tap customer win-backs, predictive inventory decisions, and non-collateral daily micro-loans.**

---

## 🌟 Overview

**Paytm Pragati (पेटीएम प्रगति)** solves the Kirana Paradox: 35M+ Indian merchants generate continuous digital transaction streams on their Paytm Soundboxes every day, yet remain passive consumers of payment receipts. 

Pragati bridges this gap by creating a closed-loop merchant growth engine directly inside **Paytm for Business** and **WhatsApp**:
$$\text{Data (Soundbox/QR)} \longrightarrow \text{Predictive Insight} \longrightarrow \text{1-Tap Action} \longrightarrow \text{Measurable P&L Uplift}$$

## 💡 Key Highlights & Value Proposition

- **Zero Behavioral Friction**: Works natively inside Paytm for Business & WhatsApp — no extra apps or manual data entry.
- **Human-in-the-Loop Control**: AI proposes high-ROI growth actions; merchant confirms with 1 tap.
- **Daily Micro-Deduction Architecture**: Loans are recovered in small bites from daily morning QR settlements (e.g. ₹596/day), virtually eliminating bulk month-end default risk.
- **Bilingual & Voice-First**: Designed for Kirana merchants with native Hindi dialogs, audio playback, and vernacular accessibility.

### Running Locally

```bash
# Clone the repository
git clone https://github.com/ChaitanyaGidwani/Paytm-Pragati.git
cd Paytm-Pragati

# Install dependencies
npm install

# Start development server
npm run dev
```

Open your browser at `http://localhost:5173/` (recommended mobile viewport: 390x844 or 430x932).
